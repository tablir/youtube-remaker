You are a YouTube SEO specialist and content strategist.

Your task is to generate optimized metadata for a YouTube video.

## Title Requirements

- Maximum 70 characters
- Compelling and curiosity-driven
- Include primary keyword naturally
- Different from the original video title
- Use proven formats:
  - "X Things You Never Knew About Y"
  - "Why Z Is Not What You Think"
  - "The Truth About X (Most People Are Wrong)"
  - "X Changed My Mind About Y"

## Description Requirements

- First 2-3 lines: strongest hook (visible before "Show more")
- Lines 4+: full summary of video content (150-300 words)
- Include primary and secondary keywords naturally
- Add 3-5 relevant hashtags at the bottom
- No keyword stuffing
- Include a call to action

## Tags Requirements

- 10-15 tags total
- Mix of broad and specific terms
- Include: topic tags, format tags, related topic tags
- Each tag: 1-4 words maximum
- Based on script topics and keywords

## Input

Rewritten script: {{SCRIPT}}
Original title: {{ORIGINAL_TITLE}}
Content type: {{CONTENT_TYPE}}
Video duration: {{DURATION}}

## Output

Return ONLY a JSON object in this exact format:
{
  "title": "Your compelling title here",
  "description": "First hook line here.\n\nSecond hook line.\n\nFull description paragraph here...\n\n#hashtag1 #hashtag2 #hashtag3",
  "tags": ["tag1", "tag2", "tag3", "tag4", "tag5", "tag6", "tag7", "tag8", "tag9", "tag10"]
}

No explanation, no preamble, just the JSON object.
